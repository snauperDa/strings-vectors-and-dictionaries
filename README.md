# Лабораторная работа №5. Строки, векторы и словари

## Автор

Колосков Дмитрий Викторович

## Вариант

Вариант 11

## Цель работы

Научиться обрабатывать текст с помощью строк, хранить последовательности в векторе и находить данные по ключу в словаре. Выполнить отдельные упражнения со строкой, вектором и словарём, а затем применить все три конструкции при обработке списка записей.

## Задачи варианта

| Часть | Задание |
|-------|---------|
| A | Сменить регистр: строчные буквы сделать прописными, а прописные — строчными. Остальные символы не менять. |
| B | Циклически сдвинуть вектор на один элемент влево. Пустой вектор не меняется. |
| C | Удалить из словаря пару по введённому ключу и вывести итоговый словарь. Отсутствующий ключ результат не меняет. |
| D | Для каждого вида вещи собрать различные места, где её находили. Вывести строки «вещь: место, место»; вещи и места упорядочить по алфавиту. Повтор одинаковой пары не добавляет новое место. |

## Используемые средства

- `<string>` — хранение и посимвольная обработка текста, `getline()`;
- `<cctype>` — проверка и преобразование регистра: `isalpha()`, `islower()`, `toupper()`, `tolower()`;
- `<vector>` — последовательность чисел, `push_back()`, `size()`, обход по индексу и диапазонный `for`;
- `<map>` — словарь «ключ — значение», `operator[]`, обход пар `first`/`second`;
- `vector<map<string, string>>` — список записей с именованными полями в части D.

## Входные данные

Программа запрашивает данные последовательно для всех четырёх частей.

### Часть A

Одна строка целиком, читается через `getline(cin, ...)`. Допускается ASCII-текст длиной не более 200 символов, включая пробелы. Пустая строка является допустимым вводом.

### Часть B

1. `n` — количество элементов вектора, целое число от 0 до 100.
2. `n` целых чисел — элементы вектора, по модулю не больше 1000.

### Часть C

1. Количество пар словаря (целое неотрицательное число).
2. Для каждой пары: ключ (строка) и значение (целое число).
3. Ключ, который нужно исключить из итогового вывода.

При повторном вводе одного и того же ключа сохраняется последнее значение.

### Часть D

1. Количество записей (целое число).
2. Для каждой записи: название вещи и место обнаружения (две строки без пробелов).

## Выходные данные

- **A** — преобразованная строка в формате `Answer: <строка>`.
- **B** — исходный вектор в строке `Vector useer: ...`, затем сдвинутый вектор в строке `Answer: ...`. Для пустого вектора выводится `EMPTY`.
- **C** — исходный словарь после строки `Final Glossary:` в виде `Key: <ключ> Value: <значение>`, затем словарь без исключённого ключа.
- **D** — исходный список записей после строки `Final Glossary:`, затем сгруппированный результат в виде `<вещь>: <места>`.
- При неверном параметре частей A–C выводится `INVALID`, и программа завершается.

## Алгоритм работы

### Часть A — смена регистра

1. Прочитать строку целиком через `getline()`.
2. Проверить успешность чтения и длину строки (не более 200 символов).
3. Просмотреть строку посимвольно.
4. Если символ является буквой, заменить его на противоположный по регистру:
   - строчную букву — на прописную;
   - прописную букву — на строчную.
5. Остальные символы (пробелы, цифры, знаки пунктуации) скопировать без изменений.
6. Вывести полученную строку.

### Часть B — циклический сдвиг влево

1. Прочитать количество элементов `n` и проверить диапазон `0 ≤ n ≤ 100`.
2. Прочитать `n` чисел, проверяя ограничение `|x| ≤ 1000`.
3. Если вектор пуст, вывести `EMPTY` и завершить работу.
4. Скопировать элементы с индексами `1..n-1` в новый вектор.
5. Добавить в конец первый элемент исходного вектора.
6. Вывести исходный и сдвинутый векторы.

### Часть C — удаление по ключу

1. Прочитать количество пар словаря.
2. Для каждой пары прочитать ключ и значение и сохранить их в `map<string, int>`.
3. Вывести исходный словарь (ключи автоматически упорядочены).
4. Прочитать ключ, который нужно исключить.
5. Вывести все пары, кроме пары с указанным ключом.
6. Если ключа нет, словарь выводится без изменений.

### Часть D — группировка вещей по местам

1. Прочитать количество записей.
2. Для каждой записи прочитать вещь и место, сохранив их в `map<string, string>` с полями `item` и `place`.
3. Добавить запись в вектор записей.
4. Вывести исходный список.
5. Для каждой записи добавить место в словарь `map<string, vector<string>>`, где ключ — вещь.
6. Перед добавлением проверить, не встречалось ли это место у данной вещи; повтор не добавлять.
7. Вывести вещи в алфавитном порядке (за счёт упорядоченности `map`) и список мест для каждой вещи.

## Пример работы

### Часть A

Входная строка (кавычки показывают границы и не вводятся):

```text
  Cat a12  dog Cat  
```

Результат:

```text
  cAT A12  DOG cAT  
```

### Часть B

Входные данные:

```text
7
-2 0 3 3 -1 4 0
```

Результат:

```text
0 3 3 -1 4 0 -2
```

### Часть C

Исходные пары:

```text
beta 2
alpha 5
beta 3
gamma -1
```

После повторного ключа `beta` в словаре остаётся значение `3`. При исключении ключа `beta` результат:

```text
alpha 5
gamma -1
```

### Часть D

Исходные записи:

```text
keys Library
bag Hall
keys Hall
keys Library
```

Ожидаемый результат по заданию:

```text
bag: Hall
keys: Hall, Library
```

## Особенности текущей реализации

- Все четыре части выполняются в одном запуске последовательно, без выбора части `A`, `B`, `C` или `D`.
- В части B приглашение вывода содержит опечатку: `Vector useer`.
- В части C формат ответа отличается от компактной записи в задании: пары выводятся построчно в виде `Key: ... Value: ...`.
- В части D места выводятся без разделителя `, `, а порядок мест соответствует порядку появления, а не алфавиту. Для контрольного примера текущая версия выводит `keys: LibraryHall` вместо `keys: Hall, Library`.
- В части A пустая строка не заменяется на `EMPTY`, а выводится пустой результат.
